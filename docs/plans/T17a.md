# T17a plan: C#, PHP and Ruby profiles

Follows `.claude/skills/add-language/SKILL.md` once per language. Resolver stays language-free; each language adds `queries/<lang>/imports.scm`, `structural/<lang>.py` (registered in `PROFILES`), a sample project and tests.

## Step 1 finding: tags gaps
- **C#**: upstream tags tag calls as `@reference.send`, which the adapter ignores, so C# has **no calls at all**. Fix: `queries/c_sharp/extra.scm` with `@reference.call` for `Foo()` (identifier callee), `a.Foo()` (member access). Constructors (`new E()`) get no CALLS edge, as in Java.
- **PHP**: calls are tagged (`foo()`, `A::b()`, `$x->m()`); receivers come out as `D`, `$x`. No gap expected.
- **Ruby**: `recv.m` and bare `m(...)`/`m` tagged. `require` is excluded by upstream, so imports need no call filtering. Gap to check: bare identifiers are tagged as calls only if not local; the adapter drops that predicate, so bare words may become false calls (expect noise, noted).

## C#
- **Import**: `using A.B;` (namespace), `using static A.B.C;` (members of class C), `using X = A.B.C;` (alias). Captured with target `A.B`; static and alias are told apart by pattern (alias capture for `X`; static needs the `static` keyword child, tested on the tree). Module `attrs["package"]` = declared namespace (file-scoped or block; first one).
- **Mapping**: namespace -> files whose `package` equals it (`ctx.by_package`). `using A.B.C` for a class: target is a namespace + class; for `using static` try the longest prefix as namespace and last segment as class (Reach `class_name`).
- **Scope**: unqualified call: class chain (`has_class_chain`), own file, then package scope = files with the same namespace. `Foo.Bar()` with `Foo` a class name: search classes named `Foo` in namespaces in scope (own, imported); members only. `x.Baz()` untyped: imports' files, capped at 5.
- **Expect wrong**: `var`-typed receivers; extension methods; partial classes (reopened across files is fine, they share a namespace); nested namespaces `namespace A { namespace B` (only declared-text name is used); global usings.

## PHP
- **Import**: `use App\Models\User;` (class), `use App\Models\User as U;`, grouped `use App\{A, B as C};`, `use function`/`const` (treated as names), `require/include(_once) 'x.php'` with a literal (also `__DIR__ . '/x.php'`) as a file import.
- **Mapping**: PSR-4 table from Package nodes' `attrs["autoload_psr4"]` (prefix -> folders, longest prefix wins) -> `<folder>/<rest>.php`. Fallback: file with matching `package` (namespace) and basename. Else external.
- **Scope**: `User::find()` and `U::find()` resolve among User's methods via binding; `$x->save()` untyped: imports' files, capped at 5; `self::`/`static::`/`$this->` use the class chain; unqualified `foo()`: own file, then same namespace.
- **Expect wrong**: autoloaded-by-classmap code, dynamic includes, facades/magic methods, namespaces relative names (`Models\User`).

## Ruby
- **Import**: `require_relative "x"`, `require "x"`, `load`. Ruby imports are plain calls, so the imports query matches `call` with method `require`/`require_relative` and a string argument. `Foo.bar` binding is by constant name, not import.
- **Mapping**: `require_relative` -> path relative to the file (+`.rb`); `require "x"` -> `<any lib/>x.rb` found by suffix `lib/x.rb`, else external. Binding: none from imports (Ruby names are global once required); the profile reaches files and uses `names=None`-style wildcard reach so `Foo.bar` is looked up among required files. Classes reopened across files are one scope: package scope is every file defining the same class names; I will model it as scope = files that define a class with the same name as the caller's owner.
- **Scope**: bare `bar` / `self.bar`: class chain, file, package_scope (reopened-class files), required files. `Foo.bar`: methods of classes named Foo in own file, reopened files, required files.
- **Expect wrong**: autoload/zeitwerk (Rails) never `require`s, so Rails apps lean on name guesses; `include`d modules; metaprogramming; `method_missing`.
