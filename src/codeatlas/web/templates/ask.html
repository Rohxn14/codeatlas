No language model key is set. CodeAtlas reads GROQ_API_KEY from the environment, and GEMINI_API_KEY too if you have one (it is used when Groq fails). It checks that a key is there; it never shows it or writes it down.

Do not type a key into a terminal: PowerShell saves every line you type in a history file. Set it as a Windows environment variable instead:

  1. Open the Start menu and search for Edit environment variables for your account.
  2. Under User variables, choose New. Name: GROQ_API_KEY. Value: paste the key. Choose OK, and OK again.
  3. Close every VS Code and terminal window, then open a new one and start the app again. A program only sees the variables that existed when it started.

On Linux or macOS, set the variable where your login shell sets its environment.
