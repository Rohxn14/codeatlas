GEMINI_API_KEY=your Gemini key

Open the file in your editor; do not type a key into a terminal, which keeps a history of what you type. .env is ignored by git. CodeAtlas takes only these two names (and CODEATLAS_* settings) from it, and a variable already set in the environment wins.
