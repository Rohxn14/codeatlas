How far to trust this

  • A score is not a probability. It is the confidence of each edge on the path multiplied together, times 0.8 for every step away from the change.
  • Test selection is measured: on two small benchmarks where code was broken on purpose, files at {{ "%.1f" | format(v.threshold) }} or more matched the tests that really failed with an F1 of about 0.84.
  • The ranking of other files is not proven: it does not yet predict which files change together better than plain git history does.
  • Calls the map could not resolve (see Coverage) are paths this page cannot follow, so a missing file here is not proof that it is safe.
